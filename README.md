# Núria Estudo 2.0

Pacote de melhoria da aplicação **Núria · Estudo da Monografia**.

## O que foi melhorado

- Interface visual mais limpa, moderna e legível em Android.
- Melhor hierarquia visual para títulos, cartões, perguntas e ações.
- Botões e áreas de toque maiores para uso no telemóvel.
- Estados de resposta do Quiz mais claros: correta/errada e indicação visual da resposta correta.
- Animações leves de navegação e feedback, respeitando `prefers-reduced-motion`.
- Persistência local do progresso de Flashcards e pontuação com `localStorage`.
- Progresso inicial passa a considerar cartões já conhecidos e cartões marcados para rever.
- Melhorias de foco/acessibilidade para teclado e toque.
- Fundo, sombras, bordas e espaçamento refinados sem alterar o banco de 120 perguntas.

## Arquivos

- `index.html` — versão melhorada pronta para substituir a versão atual.
- `source/index-original.html` — cópia de segurança da versão original recebida.
- `design/LINKS.txt` — links dos protótipos/designs criados em Figma e Canva.

## Observação

O app continua sendo um único `index.html`, mantendo a estrutura original para facilitar a publicação no GitHub/Vercel.
